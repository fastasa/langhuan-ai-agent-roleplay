# 网络边界

## 默认启动

Express 与 Vite 都固定监听 `127.0.0.1`。在没有配置第三方提供商、没有主动执行联网功能时，应用只进行浏览器与本机服务之间的请求。项目不包含遥测、崩溃回传、作者控制面或默认作者中转服务。

## 可选出口

| 能力 | 触发条件 | 可能发送的数据 | 目标 |
|---|---|---|---|
| AI 对话、嵌入、编排 | 部署者保存提供商配置并发起请求 | 提示词、所需上下文、附件、模型参数 | 部署者选择的 OpenAI 兼容 HTTPS 端点 |
| 内置提供商快捷配置 | 部署者选择并配置 Key | 同上 | OpenAI、DeepSeek、智谱或 MiniMax 官方 API |
| 天气 | 部署者配置天气 Key 并查询 | 地点与查询参数 | 部署者配置的和风天气 API 域名 |
| Codex / Claude / AGY CLI | 部署者安装、登录并主动调用本机 CLI | 由对应 CLI 决定 | 对应 CLI 服务商 |
| Colab 训练 | 部署者导出并手动上传训练包 | 导出的训练材料 | Google Colab 或部署者选择的运行环境 |
| 外部链接/图片 | 部署者主动打开，或内容中明确引用 | 浏览器常规请求信息 | 链接目标站点 |

AI 自定义端点经过出站地址校验，禁止回连本机、内网和链路本地地址，降低服务端请求伪造风险。可选代理地址只探测常见的本机回环代理端口。

## 变更要求

新增网络出口必须满足：默认关闭、由部署者明确配置或触发、目标可见、数据类型有文档、错误日志不泄露密钥，并补充自动化测试。
