# 测试口径

公开版测试只维护当前可发布契约。抽取时删除了依赖私有样例、账号/云恢复、管理员能力和已失效内部提示词快照的旧测试文件；没有使用 `skip` 把已知失败伪装成通过。

主要检查层次：

1. 服务端集成测试：空库 schema、本地作用域、核心 API、删除路由 404 和安全边界；
2. 浏览器单元测试：前台组件、仓储、状态、导入导出与本地交互；
3. 类型检查与生产构建；
4. 真实浏览器验收：`/`、`/about`、`/pixel`、移动端和删除路由；
5. 开源发行扫描：实际 Git 候选、`dist/` 和解包后的发行目录。

“代码已实现”“自动检查通过”“真实页面已验收”和“用户已接受”是不同状态，不互相替代。

- 浏览器侧 jsdom：468 个测试文件，3,870 项通过；
- 合计：547 个测试文件，4,561 项通过；
- `vue-tsc --noEmit`、生产构建、开发代理 smoke、发行扫描通过；
- `npm audit` 为 0 个已知漏洞。

真实生产启动、监听地址、空库和删除路由使用独立临时数据库另行验证；真实浏览器视觉验收仍必须单独记录，不能由 jsdom 结果代替。
