# 架构概览

## 运行形态

```text
浏览器（Vue）
    │ 仅请求同源 /api、上传与本地模型资源
    ▼
Express（127.0.0.1）
    ├─ 固定工作区作用域 local
    ├─ SQLite / sql.js 本机数据库
    ├─ 本机上传与模型目录
    └─ 部署者显式配置的可选外部服务
```

浏览器没有登录恢复流程。服务端不读取认证 Cookie，不创建用户会话，也不判断角色。业务仓储统一使用固定的 `workspace_id='local'` 与兼容键 `user_id='local'`；这些值不是账号或个人标识。

## 路由边界

- `/`：主工作区；
- `/about`：项目、隐私和许可证说明；
- `/pixel`：像素工作室；
- `/admin`：404；
- `/api/auth/*`、`/api/admin/*`、`/api/guest/*`：404。

## 数据初始化

服务端从当前 schema 创建全新数据库，不运行私有历史迁移，也不写入业务样例。初始化后只有结构性配置；角色、文档、世界、聊天和任务表为空。

## 配置与密钥

`.env` 只从项目根目录本机读取。界面中的 AI 预设属于部署者本地配置；密钥使用本机密钥加密保存。随机本机密钥与数据库同属需要一起备份的本地状态。
