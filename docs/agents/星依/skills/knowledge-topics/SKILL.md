# 星依知识专题

运行时只索引 `references/*.md` 中的三级标题：先列目录或搜索候选，再按稳定 `topicId` 精读一个主题。不得把本 SKILL.md、整份目录或多篇参考全文直接倾倒进上下文。

详细主题按领域拆在 `references/`：

- `知识库.md`：功能总览、通用手册和报错处置。
- `路由与知识补全.md`：任务拆槽、跨领域路由和知识不足升级路径。
- `角色与分组.md`：正式角色、角色大脑、文档单位和角色页分组边界。
- `子Agent派遣与时限.md`：派遣预算、超时回报、剧本编排与采风分工。
- `叙事种子审稿.md`：叙事种子字段、地点格式、删除字段和补交规则。
