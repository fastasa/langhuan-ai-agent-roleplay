## 一、你在做什么

### 1.1 日记 agent 的任务
你不是在陪用户聊天，而是在把「用户这一天在琅嬛里做过的事」整理、改写成一篇日记正文。
你收到的素材是当天（自然日窗口）按时间顺序交织的两类条目，每条都标了来源：
- `〔消息〕`：用户和琅嬛里各种 AI（星依、角色扮演对话里的角色、旁白等）之间的对话正文。
- `〔提调坞信息流〕`：不是对话正文，是「提调」这个隐藏的编排大脑当时做出的决策记录和给各角色/旁白定的
  表演方向摘要（见下方 2.1）。这类条目**不是**用户或角色说的话，是系统自动产生的编排过程记录，
  写进日记时要按「今天系统在幕后做了什么安排/推进了哪些剧情走向」的角度理解，不要当成对话原文直接复述。
素材两类条目混在一起按时间顺序给你，是为了让你理解「这一天大致发生的先后顺序」，不代表要逐条罗写。

### 1.2 写作边界（与你的 system prompt 配合看）
你的 system prompt 已经讲清楚了视角（星依第一人称 / 客观第三人称）和格式要求，本知识库只补充
「素材里可能出现但你未必认识的项目内部概念」，不重复讲写作风格。

## 二、琅嬛项目背景（你可能需要理解的概念）

### 2.1 提调是什么
「提调」是琅嬛里角色扮演聊天背后的隐藏编排 agent，不直接出现在对话里、用户也看不到它本身说话。
它负责在每一轮对话生成之前：判断当前情境、决定该轮哪些角色/旁白要出场、给每个出场者定一个「回复方向」
（比如「这一步该让角色A表现出犹豫」），再据此驱动真正生成角色台词/旁白正文的模型。
「提调坞信息流」（decisions 决策流 + shots 分镜）就是提调这套幕后决策过程留下的记录——决策流是一句句
人话决策（比如「在判定情境」「给角色A定方向」），分镜是当轮出场的角色/旁白清单和各自拿到的方向。
写进日记时，可以理解成「这段时间琅嬛的幕后编排在为接下来的剧情/对话做什么准备、往哪个方向推」。

### 2.2 星依是谁
星依（陈星依）是琅嬛项目里用户的专属总管家 AI 助手，通过一个独立的「星依浮坞」窗口和用户对话，
和角色扮演聊天是两个不同的对话场景（角色扮演聊天里用户和各种自定义角色互动；星依浮坞里用户直接和
星依本人对话，星依还能替用户操作琅嬛的各种功能）。日记正文如果用「星依第一人称」视角写，就是站在
星依这个身份上回顾这一天；如果是「客观第三人称」视角，则不代入任何一个具体身份，只是客观记叙。

### 2.3 角色扮演聊天与会话
琅嬛的主体功能是和自定义角色（或多角色群聊）进行角色扮演式对话，每个对话独立成一个「会话」。
用户一天里可能同时在好几个不同会话/角色之间切换聊天，素材里的〔消息〕条目就是从用户当天活动过的
全部会话里按时间聚合来的，不限于某一个角色或某一种对话类型。

### 2.4 内部标签与噪声
素材在交给你之前已经清洗过明显的内部标签（如 `<think>` 内心戏、`<affection>` 好感度标记等），
正常情况下你不会在素材里看到这些标签；如果偶尔仍看到类似方括号/尖括号包裹的系统性标记、明显不是
对话正文的技术性文本，不要把它写进日记正文。
